# 朝礼・終礼シート 使い方ガイド

このガイドでは、朝礼・終礼シートの使い方をキャストさん向け・店責さん向けにそれぞれ説明します。

---

## ログイン方法

1. アプリを開くと、アカウント選択画面が表示されます
2. 自分の名前をタップします
3. 店舗を選択します
4. 自分の画面に入れます

> **💡 ポイント:** 営業日は午前11時で切り替わります。11時より前にアクセスすると前日の営業日として扱われます。

---

## キャスト向け

キャストさんが使えるのは以下の5つのタブです。

### 📋 入力タブ（朝礼前に入力してね！）

朝礼前に自分の情報を入力する画面です。

**入力する内容：**
- **今日の目標** … その日の個人目標を書きます
- **来店予定（人数）** … 自分宛ての来店予定人数を入力します

**送迎が必要な場合：**
- 「送迎を使う」をONにします
- 住所を入力します
- 💡 **郵便番号で住所検索もできます！** 7桁の郵便番号を入力して「検索」ボタンを押すと、住所が自動入力されます。その後、番地や部屋番号などを追記してください

入力が終わったら **「保存」** ボタンを押してください。画面上に「保存しました」と表示されます。

> **⚠️ 注意：** 店責さんが朝礼にあなたを追加していないと保存できません。「朝礼に未登録です」と出たら店責さんに声をかけてください。

---

### 📋 朝礼タブ

店責さんが入力した朝礼の情報を確認できます（閲覧のみ）。

**見られる情報：**
- 出勤キャストの一覧
- 各キャストの月間売上・ドリンク数
- 来店予定人数
- 各キャストの目標

---

### 📋 終礼タブ

終礼の情報を確認できます（閲覧のみ）。

**見られる情報：**
- **本日の売上** … その日の店舗売上
- **今月の店舗売上** … 月の累計売上
- **自己採点一覧** … 出勤しているキャスト全員の自己採点と目標が表示されます

---

### 📋 振り返りタブ（終礼前に入力してね！）

その日の自分の振り返りを入力する画面です。

**入力する内容：**
1. **自己採点（1〜10点）** … ボタンで点数を選んでタップします
2. **振り返りコメント** … 一言コメントを書きます

入力が終わったら **「保存」** ボタンを押してください。

---

### 📋 伝言板タブ

店責さんが投稿した伝言を確認できます（閲覧のみ）。

**見られる情報：**
- 伝言の内容
- 投稿者と日付
- 対応状況（未対応 / 対応中 / 完了）
- 店責さんからのフィードバック

> **💡 ポイント：** キャストさんは閲覧のみで、投稿や状態変更はできません。

---

## 店責向け

店責さんが使えるのは以下の4つのタブです。

### 📋 朝礼タブ

その日の朝礼情報を管理する画面です。

**できること：**

#### 出勤キャストの追加
- キャスト名を入力して検索 → 追加ボタンで出勤者を登録
- 各キャストの以下の情報を入力できます：
  - **月間売上**
  - **月間ドリンク数**
- キャストが入力した **来店予定人数** と **目標** は自動で表示されます
- 不要なキャストは「✕」ボタンで削除できます

#### 自分の情報入力
- **自分の目標** を入力できます
- **送迎が必要な場合：** 「送迎を使う」をONにして住所を入力（郵便番号検索も可）

入力が終わったら **「保存」** ボタンを押してください。

---

### 📋 終礼タブ

売上入力と自己採点の管理画面です。

**売上入力：**
- **本日の売上** … その日の店舗売上を入力
- **今月の店舗売上** … 月の累計を入力

**自己採点一覧：**
- 出勤キャスト全員の自己採点を一覧で確認できます
- 各キャストの **目標** と **採点（点数・コメント）** が表示されます
- まだ採点していないキャストには「未記入」と表示されます

**自分の振り返り：**
- 店責さん自身の自己採点（1〜10点）とコメントも入力できます

---

### 📋 送迎タブ

送迎が必要なキャストの一覧を確認・コピーできます。

**見られる情報：**
- 店舗名・日付
- 送迎が必要なキャストの名前と住所

**コピー機能：**
- 「コピー」ボタンを押すと、送迎一覧がテキスト形式でクリップボードにコピーされます
- そのままLINEなどに貼り付けて共有できます

**コピーされるフォーマット例：**
```
【○○店】 3/25 送迎一覧

・鈴木あい
　渋谷区道玄坂1-2-3

・田中みく
　新宿区歌舞伎町2-4-5
```

---

### 📋 伝言板タブ

スタッフへの連絡事項を管理する画面です。

**できること：**
- **新しい伝言を投稿** … テキストを入力して投稿
- **状態を変更** … 未対応 → 対応中 → 完了 のステータス管理
- **フィードバックを記入** … 各伝言に対してコメントを追加
- **絞り込み** … 「すべて」「未対応」「対応中」「完了」でフィルタリング

---

## よくある質問

**Q. 保存ボタンを押したのに反応がない？**
→ 画面の上部に保存完了メッセージが表示されます。ページが下にスクロールしている場合は少し上に戻ると見えます（長いページでは画面上部にフロート表示されます）。

**Q. 「朝礼に未登録です」と表示される**
→ 店責さんがまだ朝礼にあなたを追加していません。店責さんに声をかけてください。

**Q. 郵便番号検索で住所が出てこない**
→ ハイフンなしの7桁（例：1500043）で入力してください。

**Q. 昨日のデータを見たい**
→ 現在は当日のデータのみ表示されます。過去のデータは表示できません。

**Q. 専任（本部）の方は？**
→ ログイン後に店舗を選択すると、その店舗の店責と同じ画面・機能が使えます。

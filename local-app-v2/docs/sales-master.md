# 売上ダッシュボードの参照元

売上ダッシュボードと専任画面の月次進捗は、ESPマネージャー【マスター】の
`AirREGI・Rose売上_YYYY-MM` タブを読み取り、営業管理売上を表示します。
営業管理売上は、日別の **AirREGI売上＋Rose使用数** です。

## 設定

- Vercelの環境変数 `SALES_MASTER_SPREADSHEET_ID` に、参照するマスターブックのIDを設定してください。
  未設定の場合は取得エラーを表示します。IDや実績データをソースコードに含めないでください。
- Vercelで使用中のGoogleサービスアカウントに、このブックの閲覧権限が必要です。
  権限がない場合は取得エラーを表示します。公開共有にする必要はありません。
- マスターは読み取り専用です。ダッシュボードからの書き込みはありません。
- キャッシュは最大5分です。マスターの訂正も同じ間隔で反映されます。

## 集計

- 対象期間の年月から参照タブを決め、シートのメタデータで存在を確認します。
- 店舗は1行目の店舗名、売上とRoseは2行目の指標名で対応づけます。
  列位置だけでは対応づけません。名称変更・新店舗追加時は `STORE_HEADERS` も更新してください。
- 日別行だけを集計し、「今月合計」「営業管理売上」などの集計行は加算しません。
- 期間合計・グラフは指定期間の日別値を使用します。月間累計は月初から計算した後で
  指定期間に絞るため、週次や日付指定でも累計に月初分が含まれます。
- 両方のセルが数値のときだけその日の売上を確定します。数値の0は0円、
  空欄・数式エラー・欠けた日付行は未入力です。過去の終礼・Airレジ同期表には代替しません。
- 月初以降に未入力日がある場合は、月間累計・達成率も未確定として表示します。
  全店・ブランドの合計も、未入力を0円として扱いません。グラフは該当日を空白にします。
- 月別タブがない期間は `missingSalesMonths` に年月を返し、売上は未入力と表示します。
  マスターに存在しない過去月を比較する場合は、その月のタブを用意する必要があります。

終礼の入力・保存とキャスト向け終礼閲覧は、従来の運用データを使用します。

## 月別の売上目標

`DATA_SPREADSHEET_ID` の運用ブックに `sales_targets` タブを作り、1行目を見出し、
A列を `yearMonth`（文字列 `YYYY-MM`）、B列を `storeCode`、C列を `targetSales`（円の整数）
として管理します。D列に任意の店舗名を添えても構いません。金額はコードや公開GitHubに含めません。

対象月と店舗が一致する設定を月次進捗で優先し、ブランド・全店目標と達成率も再計算します。
設定がない月・店舗は従来の店舗設定の目標を使います。0円の設定も有効です。
年月と店舗の重複、空欄・負数・数式エラーなどの不正な金額は取得エラーになります。
別の月には影響しないため、翌月は新しい年月の行を追加してください。反映まで最大5分です。

## 検証

`npm test` で、店舗の対応・Rose加算・月またぎ・月途中の累計・実際の0と欠損の区別・
参照権限エラー・ダッシュボードの他データとの結合を確認します。
